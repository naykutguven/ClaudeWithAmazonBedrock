# Claude with Amazon Bedrock

Just my practice code and notes while working through the
Claude with Amazon Bedrock course on Claude Academy.

Nothing here is polished or official. Expect half-finished experiments, scratch code,
and notes to myself. If it's useful to you, great, but don't treat it as a reference.

## Setup

Uses [uv](https://docs.astral.sh/uv/):

```bash
uv sync
```

Put AWS credentials/region in a `.env` file (gitignored) or configure the AWS CLI as usual.
